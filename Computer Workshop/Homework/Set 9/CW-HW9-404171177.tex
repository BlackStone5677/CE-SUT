\section{Introduction}

Being efficient is one of the most important features of a sorting algorithm, Perhaps the most important. \href{https://xkcd.com/3026/}{Stalin Sort} aims to maximize in efficiency while maybe not paying the most attention to others features different sorting algorithms have. It is wonderfully great for huge arrays that do not behold sensitive data, or if you have any problems with said data.

\section{Algorithm Description}

Stalin Sort checks the array one-by-one, when an item is out of order, it deletes it from the array. In the end the array is completely sorted.

\begin{algorithm}
\caption{Stalin Sort}
\begin{algorithmic}[1]
\IF{array[n] <= array[n+1]}
    \STATE Put array[n] into a new array
\ENDIF
\end{algorithmic}
\end{algorithm}

\section{Time Complexity}

The running time of Stalin Sort is given by the equation:

$$T(n) = \sum_{i=1}^{n}{\  1}$$

which resolves to:
$$T(n) \in \mathcal{O}(n)$$
